登录态 Cookie 被设成了整个主域可见，任意子域都能读到，一个被拿下的子站就能劫走所有人的会话：域属性必须精确到必要主机；路径属性必须收窄到必要前缀；会话 Cookie 不得跨子域；不得省略域属性让浏览器默认放宽；同站策略必须与会话用途一致；批量校验各 Cookie 独立。任何会话 Cookie 的域都不会覆盖其它主机，路径属性不会为空。
